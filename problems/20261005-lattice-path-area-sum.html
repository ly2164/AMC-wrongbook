菱形格路径的面积和：一次镜像对合把 252 条路径折成「一半面积 × 路数」

日期：20261005
成员：YC
题目：2025AMC8(25)
知识点：Lattice Paths

题目要的不是逐条路径的面积，而是所有路径面积的总和——一旦目标变成"总和"，就不该去数路径，而该去找把路径集合一分为二的那个对称。交换东北 / 西北的镜像对合把每对路径的面积凑成恒定的 25，总和立刻塌缩成 $\binom{10}{5} \times \frac{25}{2}$。

一、错题原题

Makayla finds all the possible ways to draw a path in a $5\times5$ diamond-shaped grid. Each path starts at the bottom of the grid and ends at the top, always moving one unit northeast or northwest. She computes the area of the region between each path and the right side of the grid. Two examples are shown in the figures below. What is the sum of the areas determined by all possible paths?

中文翻译：Makayla 找出了一个 $5\times5$ 菱形网格中所有可能的画法。每条路径都从网格底部出发、在顶部结束，每一步恰好向东北或向西北走一格。她算出每条路径与网格右侧围成的那块区域的面积。图中给出了两个例子。请问所有可能路径所确定的面积之和是多少？

📌 官方答案（LIVE by Po-Shen Loh）： https://live.poshenloh.com/past-contests/amc8/2025/problem/25
官方给出的正确选项为 (B) 3150，本站解析与之一致。

二、错误原因诊断

常见错误错在哪
答 6300这是"路数 × 整块面积"的直线思维：$\binom{10}{5} \times 25 = 6300$。错在把每条路径的平均面积当成了整个菱形的 25。实际上只有最靠左的那条路径才围出满格 25，靠右的大多只围出十来个格子，真实平均值只有 $25/2 = 12.5$。
「答案 3150，但路径数算成 126」最隐蔽的蒙对：误以为第一步的方向固定（只从"先东北"出发开始数），得 $\binom{9}{4} = 126$ 条，再用"整块面积 25"去乘，$126 \times 25 = 3150$——与正确答案数值完全相同。两条不同的错误路径撞出同一个数，说明不能靠答案反推方法是否正确。自查办法：路径总数必须是偶数（镜像配对），$126$ 是偶数也不该蒙混过关，但必须能说清"$252$ 条、平均 $12.5$"这才是对的。
根本问题：没有意识到"求所有路径对应量的总和"是一道对称性题而不是计数题。默认思路是"逐条路径算面积再相加"，于是要么算到崩溃（252 条），要么偷懒套一个平均面积却不知平均是多少。正确入口是：找一个保持路径集合不变的对合（这里是镜像），让每对路径的目标量之和成为常数，总和 = 路数 × 常数的一半。

三、正确解法

方法一：镜像对合 + 配对求和（推荐，一分钟版）

第 1 步 · 建立斜坐标系。用 $(i, j)$ 表示"已经向东北走了 $i$ 步、向西北走了 $j$ 步"。这样 5×5 菱形就是斜着放的正方形 $0 \le i, j \le 5$：底部角点 $B = (0,0)$，顶部角点 $T = (5,5)$，右角点 $R = (5,0)$。

第 2 步 · 数路径。从 $(0,0)$ 到 $(5,5)$ 共走 $10$ 步，其中东北、西北各 $5$ 步，故路径总数

$$N = \binom{10}{5} = 252 .$$

第 3 步 · 说清"右侧"与"面积"。右侧边界就是"先连续 5 步东北、再连续 5 步西北"这条路径。面积以一个单位菱形格为 $1$ 计，整块 $5\times5$ 菱形面积 $= 25$。记 $A(P)$ 为路径 $P$ 与右侧围出的面积，则 $0 \le A(P) \le 25$。

第 4 步 · 关键：对合。把路径上每一步的"东北"与"西北"互换，得到 $P^{*}$（关于竖直轴的镜像）。这是路径集合上的一个对合（自己作用两次回到原点，且不漏不多）。

镜像把"路径与右侧围出的区域"映成"$P^{*}$ 与左侧围出的区域"。而路径 $P$ 与右侧围的区域、$P^{*}$ 与左侧围的区域，恰好拼成整个菱形（被 $P$ 与 $P^{*}$ 两条路从中间切开）。因此

$$A(P) + A(P^{*}) = 25 \qquad (\forall P).$$

第 5 步 · 求和。记 $S = \sum_P A(P)$。把上式对所有 $P$ 求和：

$$\sum_P A(P) + \sum_P A(P^{*}) = 252 \times 25 = 6300 .$$

由于 $P \mapsto P^{*}$ 是双射，$\sum_P A(P^{*}) = S$，故

$$2S = 6300 \;\Longrightarrow\; S = 3150 .$$

等价地说：平均面积恰好是整块菱形的一半，$\dfrac{25}{2} = 12.5$，所以 $S = 252 \times 12.5 = 3150$。

答案：3150，对应选项 (B)。

方法二：小规模手算找规律，再验证通式

252 条不可能手算，那就先算最小的非平凡情形 $n = 2$。2×2 菱形只有 $\binom{4}{2} = 6$ 条路径，把"每条路径进入每个水平条带时所处的 $i$ 坐标"列出来，面积就是 $\sum_{j}(n - p_j)$：

四、知识内核提炼

核心知识点：「求所有路径对应量的总和」的标准解法不是计数，而是找一个保持路径集合不变的对合（对合映射），使每对路径的目标量之和为常数。本题的对合是"交换东北 / 西北"的镜像，常数是菱形总面积 $25$，于是总和 $=$ 路径数 $\times$ 常数 $/$ 2，通式 $\dfrac{n^2\binom{2n}{n}}{2}$ 对任何 $n\times n$ 立刻成立。

必须掌握的要点：

  1. 斜坐标 $(i,j)$（$i$ = 东北步数，$j$ = 西北步数）把菱形变成正方形 $0\le i,j\le 5$，路径 $=$ 从 $(0,0)$ 到 $(5,5)$ 的单调格路，共 $\binom{10}{5} = 252$ 条。
  2. 「右侧」是"先全东北再全西北"那条边界路径；面积以单位菱形格计，整块 $5\times5$ 菱形面积 $= 25$，故 $A(P) \in [0, 25]$。
  3. 镜像（交换东北 / 西北）是对合：它把路径两两配对（可能有自配对），并把 $A(P)$ 映成 $25 - A(P)$。"每对之和是常数"是解题的全部杠杆。
  4. 平均面积恒为 $\dfrac{n^2}{2}$，与路径条数无关。这条结论可迁移：任何"菱形 / 三角形网格中所有单调路径某量的总和"型题目，先找对合、再写"路数 × 半"即可。

第 1 题 · 2×2 最小情形全枚举 ★ 形式｜完整列举

先做最小的非平凡情形：一个 $2\times2$ 菱形网格，路径从底部到顶部，每步向东北或向西北。共有多少条路径？把每条路径与右侧围成的面积逐条算出，并求面积之和。

👉 点击查看解析
答：6 条路径，面积依次为 $0,1,2,2,3,4$，总和 $=12$

路径数 $=\binom{4}{2} = 6$。面积按条带算：路径在第 $j$ 个水平条带里进入时的 $i$ 坐标记作 $p_j$，则 $A = \sum_{j}(n - p_j)$，这里 $n = 2$。

$NWNW$1与 $WNWN$ 镜像配对

$WNWN$3与 $NWNW$ 镜像配对

和 $= 0 + 1 + 2 + 2 + 3 + 4 = 12$。用通式核对：$\dfrac{n^2\binom{2n}{n}}{2} = \dfrac{4 \times 6}{2} = 12$ ✓，平均面积 $= 2 = \dfrac{n^2}{2}$ ✓。

要点：最小情形就能看出平均面积 = 整块的一半：$12 / 6 = 2 = 4/2$。考场上手算 6 条路径验证一次，比死记通式踏实得多。

第 2 题 · 3×3 换参数 ★★ 形式｜换约束参数

把网格换成 $3\times3$ 菱形，其余不变（路径从底部到顶部，每步东北或西北，共 $6$ 步）。求路径条数与面积之和。

👉 点击查看解析
答：$\binom{6}{3} = 20$ 条，面积之和 $= 90$

用对合法：路径数 $N = \binom{6}{3} = 20$，整块面积 $n^2 = 9$。镜像配对使每对之和为 $9$，故平均面积 $9/2 = 4.5$，总面积和

$$S = 20 \times \frac{9}{2} = 90 .$$

程序逐条枚举 20 条路径（不依赖对称性）验证得 $90$，且平均 $4.50$，吻合。

注意：平均面积 $4.5$ 是半整数，但总和仍是整数 $90$，因为 $\binom{6}{3} = 20$ 是偶数。这消除了"半整数怎么乘"的疑虑。

要点：$\binom{2n}{n}$ 恒为偶数（$n \ge 1$），所以 $n^2\binom{2n}{n}/2$ 永远是整数。看到 $n^2$ 是奇数导致平均面积带 $0.5$ 时，不必担心总和对不上。

第 3 题 · 面积门槛子计数 ★★★ 形式｜附加约束子计数

在 $4\times4$ 菱形（$\binom{8}{4} = 70$ 条路径）中，统计路径与右侧围成的面积不小于 8（即不小于整块面积的一半）的路径条数。

👉 点击查看解析
答：39 条（其中面积恰为 8 的有 8 条）

镜像配对给出 $A(P) + A(P^{*}) = 16$。把 70 条路径按"面积是否恰为 8"分成两类：

  • 面积恰为 8（落在中线）：程序枚举得 8 条。它们各自满足 $A = 16 - A$，是"自配对"的；
  • 其余 $70 - 8 = 62$ 条：两两配对，每对一小一大，恰好各有一条 $\ge 8$，贡献 $31$ 条。

于是面积 $\ge 8$ 的路径数 $= 31 + 8 = \boxed{39}$。

易错点：直接写"一半"会得到 $70/2 = 35$，漏掉了中间那 8 条。只有当 $n^2$ 为奇数（如 $n = 5$，$n^2 = 25$）时，面积才永远取不到整数中点，两半才真的各占一半。程序核对：$n=5$ 时面积 $>12.5$ 的 126 条、$<12.5$ 的 126 条，无平局。

要点：配对计数时务必先扣出自配对的"平局"路径：$n^2$ 偶数时中线上有解，奇数时没有。这是"对合计数"最常见的漏项。

第 4 题 · 通项证明 + n=6 ★★★★ 形式｜一般化通项 + 证明

证明：对任意正整数 $n$，$n\times n$ 菱形网格中所有路径（从底部到顶部，每步东北或西北）与右侧围成面积的总和为 $\dfrac{n^2\binom{2n}{n}}{2}$。并据此求出 $n = 6$ 时的总和。

👉 点击查看解析
答：$\dfrac{n^2\binom{2n}{n}}{2}$；$n=6$ 时为 $16632$

证明。斜坐标下 $n\times n$ 菱形为 $0\le i,j\le n$，路径从 $(0,0)$ 到 $(n,n)$，共 $\binom{2n}{n}$ 条。对任意路径 $P$，令 $P^{*}$ 为逐步交换东北 / 西北得到的镜像。$P$ 与右侧围的区域、$P^{*}$ 与左侧围的区域恰好拼成整个菱形，故 $A(P) + A(P^{*}) = n^2$。又 $P \mapsto P^{*}$ 是双射，故

$$2\sum_P A(P) = \binom{2n}{n} n^2 \;\Longrightarrow\; \boxed{\sum_P A(P) = \tfrac{n^2}{2}\binom{2n}{n}} .$$

数值验证（程序逐条枚举，不用对称性）：$n=2,3,4,5,6$ 分别得 $12, 90, 560, 3150, 16632$，与公式逐一吻合。

代入 $n = 6$：$\binom{12}{6} = 924$，故

$$S = \frac{36 \times 924}{2} = 36 \times 462 = 16632 .$$

要点：通式的结构值得背下来：路数 $\binom{2n}{n}$ × 整块面积 $n^2$ ÷ 2。它对任意 $n$、任意"关于中线对称"的路径量都成立（不限于面积）——例如"所有路径上方格子数之和"也是同一个值。

第 5 题 · 奇数面积的一半分割 ★★★★★ 形式｜极值结构证明

回到 $5\times5$ 菱形（$252$ 条路径）。证明：没有任何一条路径围出的面积恰好等于 $12.5$；并求出面积不小于 13 的路径条数。

👉 点击查看解析
答：不可能等于 12.5；面积 $\ge 13$ 的路径恰有 $126$ 条

第一问（不可能）：面积是单位菱形格的整数个数，必为整数；而 $\dfrac{25}{2} = 12.5$ 不是整数。所以中线 $A = 12.5$ 上一条路径都没有。

第二问（正好一半）：把 $252$ 条路径按镜像配成 $126$ 对。每对满足 $A(P) + A(P^{*}) = 25$，且 $A$ 都是整数，故每对中恰有一条 $\ge 13$、恰有一条 $\le 12$（不存在平局，因为 25 是奇数，$12.5$ 取不到）。于是

$$ \#\{P : A(P) \ge 13\} = 126 = \frac{252}{2} = \frac{\binom{10}{5}}{2} .$$

程序核对：面积 $\ge 13$ 的 126 条、$\le 12$ 的 126 条，合计 $252$，无一遗漏、无一重复。

补充事实：面积恰好为 $13$（最小的大侧面积）的路径有 20 条（程序统计），它们正好是"从最左路径出发做 5 次相邻交换"能覆盖的那一档；对称地面积恰好为 $12$ 的也有 20 条。

要点：奇数面积时对合必无平局，于是"一大一小"严格成立、两半条数完全相等；偶数面积时中线上可能站着若干路径，必须先扣掉它们（见 EX3）。判断题里先问一句「$n^2$ 是奇是偶」能省掉一半错误。

六、方法总结卡片（贴在错题本上）

菱形格「路径总和」· 三行卡

  1. 斜坐标 + 数路数：$(i,j) = (\text{东北步数},\text{西北步数})$，菱形变正方形 $0\le i,j\le n$，路径 $=$ $(0,0)\to(n,n)$ 的单调路，共 $\binom{2n}{n}$ 条。
  2. 找对合：交换东北 / 西北＝镜像，作用两次回到原点且不漏不多。$A(P)$ 被映成 $n^2 - A(P)$，于是每对路径的目标量之和恒为整块面积 $n^2$。
  3. 求和：$2S = \binom{2n}{n}\, n^2$，即 $S = \dfrac{n^2\binom{2n}{n}}{2}$，平均面积 $\dfrac{n^2}{2}$。要数"一半"时先扣掉落在中线的路径（$n^2$ 偶数才有）。

口诀：求和先找对称；交换方向成对影，每对相加是整块；总和＝路数乘半面积。
