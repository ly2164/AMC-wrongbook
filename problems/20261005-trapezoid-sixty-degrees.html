60° 等腰梯形：把「正整数边长 + 固定周长」翻译成一个整数区间的计数

日期：20261005
成员：YC
题目：2025AMC8(24)
知识点：Trapezoid

两条等腰、两个 60° 底角——一旦把「底角 60°」翻译成「每条腰在水平方向投影恰是腰长的一半」，上底与下底之差就被钉死为腰长，整个四边形塌缩成一个自由变量。周长 30 于是变成一条一元一次方程，剩下的问题只是数区间里的整数。

一、错题原题

In trapezoid ABCD, angles B and C measure 60° and $AB = DC$. The side lengths are all positive integers and the perimeter of $ABCD$ is 30 units. How many non-congruent trapezoids satisfy all of these conditions?

中文翻译：在梯形 $ABCD$ 中，角 $B$ 与角 $C$ 都是 $60^\circ$，且 $AB = DC$。四条边的长度都是正整数，且 $ABCD$ 的周长为 30。满足全部这些条件的互不全等的梯形共有多少个？

📌 官方答案（LIVE by Po-Shen Loh）： https://live.poshenloh.com/past-contests/amc8/2025/problem/24
官方给出的正确选项为 (E) 4，本站解析与之一致。

二、错误原因诊断

常见错误错在哪
答 3多半是漏掉了最"扁"的那一个：$AD = 12,\; BC = 14,\; AB = DC = 2$。这个解的腰只有 2、上下底差也只有 2，画出来"看着不像梯形"，于是被下意识划掉了。另一种漏法是只枚举了 $BC \in \{11,12,13\}$ 而忘了 $BC = 14$ 仍满足 $AD = 12 \ge 1$。
答 5（或任何多于 4 的数）把关系写成了 $AD = BC + l$（即认为上底比下底长）。当 $\angle B = \angle C = 60^\circ$ 且 $B,C$ 是同一底边上的两个角时，梯形是"下底长、上底短"的，$60^\circ$ 这个锐角只可能出现在长底一侧；写成加号会凭空多造出一批 $2b + 3l = 30$ 的解。另一种多算来自没检查不全等：$AD = 6,BC = 12,l = 6$ 与 $AD = 3,BC = 9,l = 6$ 形状不同但常被草草视作"同一族"而合并。
根本问题：没有意识到本题的四个条件里真正起作用的只有两条：$AB = DC$ 把它变成等腰梯形（于是两个底角自动相等，且上下底对称），$\angle B = \angle C = 60^\circ$ 给出腰的水平投影恰为腰长的一半。没抓住"投影 = 腰长一半"这个特殊角度，就只能在四个边长之间硬解方程组，既慢又容易把加号写成减号。

三、正确解法

三、正确解法

与官方解法同源：本站方案一的核心不变量与官网 2025AMC8(24) 的书面解答一致——过 $A$ 作 $CD$ 平行线得等边三角形 $ABE$ 且 $ADCE$ 为平行四边形，于是周长 $=3x+2y=30$；数其正整数解 $\{2,4,6,8\}$ 得 4。
表述差异：官网直接给出「哪些线段相等」，本站把「为何必然相等」用角与平行四边形两条理由逐步证出。
本站的增量在于把官网因篇幅省略的中间推理与易错点补全；若有另一条思路，作为方案二呈现。

方案一｜补一条平行线，构造等边三角形（官方解法，推荐）

第 1 步 · 认角色。$AD \parallel BC$ 且 $AB = DC$，所以这是等腰梯形，$B,C$ 是下底 $BC$ 上的两个底角。由 $AB = DC$ 且两腰对称，$\angle B = \angle C = 60^\circ$。

第 2 步 · 过 $A$ 作 $CD$ 的平行线，交 $BC$ 于 $E$。这一条辅助线是全题的钥匙，也是官网提示 1 指定的动作：

官网提示 1：Draw a line through \(A\) parallel to line \(CD\).
官网提示 2：The perimeter becomes \(3x+2y\) for positive integers \(x,y\).

第 3 步 · 为什么 $\triangle ABE$ 是等边三角形。因为 $AE \parallel CD$，所以 $\angle AEB = \angle DCB = 60^\circ$（同位角）；又 $\angle ABE = \angle ABC = 60^\circ$。三角形内角和 $180^\circ$，故 $\angle BAE = 60^\circ$，三边相等——$\triangle ABE$ 是等边三角形。因此图中所有标 $x$ 的线段彼此相等：

$$AB = BE = AE = x .$$

第 4 步 · 为什么 $ADCE$ 是平行四边形（但不一定是菱形）。$AE \parallel DC$ 且 $AD \parallel EC$，两组对边分别平行，故 $ADCE$ 是平行四边形，于是所有标 $y$ 的线段彼此相等：

$$AD = EC = y,\qquad CD = AE = x .$$

关键提醒：$y$ 不必等于 $x$。官网特意强调「not necessarily equal to $x$」——平行四边形只保证两组对边各自相等，跨组相等需要额外条件（那是菱形），本题并未给出。这是本题最容易被误用的一步。

第 5 步 · 周长写成 $3x + 2y$。官网在此处略过了「周长怎么用 $x,y$ 表示」这一步，我们补上。$ADCE$ 是平行四边形，故两组对边分别相等：$AD = EC = y$、$AE = DC = x$。再由 $E$ 在 $BC$ 上，$BC = BE + EC = x + y$。于是沿四边走一圈

$$P = AD + BC + CD + AB = y + (x+y) + x + x = 3x + 2y .$$

其中 $CD$ 段本身等于 $x$、$AD$ 段等于 $y$，加上底 $BC$ 拆成 $x+y$，三处相加正好凑出 $3x + 2y$。与官网一致：周长 $= 3x + 2y$，它同时等于 $30$，于是问题化为数方程 $3x + 2y = 30$ 的正整数解。

第 6 步 · 数正整数解。由 $2y = 30 - 3x$ 为偶数，而 $3x$ 的奇偶性与 $x$ 相同，故 $30 - 3x$ 为偶数 $\Leftrightarrow$ $x$ 为偶数。再看上界：$x = 10$ 时 $y = \frac{30-30}{2} = 0$，不是正整数，故 $x < 10$。合起来 $x$ 取小于 $10$ 的正偶数：

$$x \in \{\,2,\,4,\,6,\,8\,\} \quad\Longrightarrow\quad y = \frac{30-3x}{2} = 12,\ 9,\ 6,\ 3 .$$

共 4 组正整数解，对应 4 个互不全等的梯形，答案 E。

方案二｜坐标投影法：把 60° 翻译成「半个腰长」

不补辅助线，改用投影。第 1 步 · 认角色。记 $AB = DC = l$，$BC = b$（下底），$AD = a$（上底）。

第 2 步 · 把 60° 翻译成水平投影。从 $B$ 出发沿 $BA$ 走一步，水平方向前进 $l\cos 60^\circ = \dfrac{l}{2}$，竖直方向上升 $\dfrac{\sqrt3}{2}l$。左腿如此，右腿对称地也向右让出 $\dfrac{l}{2}$，所以

$$a = b - 2\cdot\frac{l}{2} = b - l .$$

这一步是本题的题眼：选 60° 就是为了让投影变成半个腰长，公式从而退化成纯整数运算，不需要处理 $\sqrt3$。

第 3 步 · 周长变成一元一次方程。

$$a + b + 2l = (b-l) + b + 2l = 2b + l = 30 .$$

只剩 $b$ 一个未知数：$l = 30 - 2b$，$a = b - l = 3b - 30$。

第 4 步 · 边长为正整数 $\Rightarrow$ 两条不等式。

$$\begin{cases} l = 30-2b \ge 1 &\Rightarrow\ b \le \dfrac{29}{2} = 14.5 \Rightarrow b \le 14 \\[2mm] a = 3b-30 \ge 1 &\Rightarrow\ b \ge \dfrac{31}{3} \approx 10.33 \Rightarrow b \ge 11 \end{cases}$$

于是 $b \in \{11,12,13,14\}$，整数区间里 4 个值 $\Rightarrow$ 4 个梯形。四组 $(a,b,l)$ 两两不同，故对应梯形互不全等。

本法与方案一同源：$b = x+y$、$l = x$、$a = y$，代入 $a = b - l$ 正是 $y = (x+y) - x$。方案一的 $3x+2y=30$ 展开即 $2(x+y)+x=30$，与方案二的 $2b+l=30$ 是同一个方程，只是选了两条不同的未知量作基准——方案一数的是 $x$ 的偶数性，方案二数的是 $b$ 的区间长度，因此得数相同。

一句话总结：方案一补平行线把周长写成 $3x+2y$，靠"$x$ 取小于 10 的正偶数"得 4；方案二用投影把周长写成 $2b+l$，靠"$b$ 锁在 $[11,14]$"得 4。两条路是同一个方程的两种参数化。

方案二（续）｜按腰长枚举（更快，且天然给出参数表）

直接猜 $l$。由 $2b + l = 30$ 且 $b$ 为整数，得 $l$ 必须是偶数（否则 $30 - l$ 为奇数，$b$ 不是整数）。再由上底为正：

$$a = b - l = \frac{30-l}{2} - l = \frac{30-3l}{2} \ge 1 \;\Longrightarrow\; 30 - 3l \ge 2 \;\Longrightarrow\; l \le \dfrac{28}{3} \approx 9.33 \;\Longrightarrow\; l \le 9 .$$

结合"$l$ 为正偶数"：$l \in \{2,4,6,8\}$，4 个值——这正是官网解答的 $\{2,4,6,8\}$。代回得

$$l=2:\ (a,b)=(12,14);\quad l=4:\ (9,13);\quad l=6:\ (6,12);\quad l=8:\ (3,11).$$

与方法二的表恰好互为逆序，两条路交叉验证，结论可靠。

一句话总结：$\text{周长} = 2b + l$ 固定了 $b$ 与 $l$ 的一一对应；正整数条件把 $b$ 锁在 $[\,11,14\,]$ 或把 $l$ 锁在 $\{\,2,4,6,8\,\}$ 里，两端都恰好 4 个。
验证技巧：把 4 个解代回三条硬条件逐条打勾：① 周长 $a+b+2l = 2b+l$，四个 $b$ 都让 $2b + (30-2b) = 30$ 恒成立；② 底角——由 $a = b - l$ 反推每条腰的水平投影是 $\frac{b-a}{2} = \frac{l}{2} = l\cos 60^\circ$，故 $\angle B = \angle C = 60^\circ$；③ 全等——三边长 $(2,11,8)$ 类差异明显。反向自检：若某个梯形没被列出，则它的 $b$ 必须落在 $\{10 \text{ 及以下}\} \cup \{15 \text{ 及以上}\}$，前者使 $a \le 0$，后者使 $l \le 0$，两者都违反"正整数边长"，故无遗漏。

四、知识内核提炼

核心知识点：等腰梯形里，底角 $\theta$ 通过「腰的水平投影 $l\cos\theta$」把上下底锁死：上底 $a = b - 2l\cos\theta$。当 $\theta = 60^\circ$ 时 $2\cos\theta = 1$，于是 $a = b - l$，周长 $a + b + 2l = 2b + l$ 退化为单个整数 $b$ 的线性函数——"几何题"就此变成"数区间里的整数"。

必须掌握的要点：

  1. 等腰梯形的两个底角自动相等；本例 $\angle B, \angle C$ 同在底边 $BC$ 上，所以它们同时是 $60^\circ$，两腰 $AB, DC$ 对称。
  2. 腰在水平方向的投影是 $l\cos 60^\circ = \dfrac l2$，两腰各让出 $\dfrac l2$，所以 $a = b - l$。误写成 $a = b + l$ 是本题最常见的致命错误。
  3. 边长为正整数 $\Rightarrow$ 每条边都给出一条整数不等式：$l \ge 1 \Rightarrow b \le 14$；$a \ge 1 \Rightarrow b \ge 11$。计数就是 $\lfloor\text{上界}\rfloor - \lceil\text{下界}\rceil + 1$。
  4. "互不全等"在这题里是免费送的：$l$ 与 $b$ 一一对应，$l$ 不同则边长集合不同，必然不全等。若某道变体把"互不全等"换成"面积不同"或"对角线不同"，才需要额外检查。

第 2 题 · 大周长换参数 ★★ 形式｜换约束参数

条件不变（等腰、底角 $60^\circ$、正整数边长），把周长改成 40。求梯形个数，并写出所有 $(AD, BC, AB)$。

👉 点击查看解析
答：6 个：$(2,14,12),\ (5,15,10),\ (8,16,8),\ (11,17,6),\ (14,18,4),\ (17,19,2)$

$2b + l = 40$：$l = 40 - 2b \ge 1 \Rightarrow b \le 19.5 \Rightarrow b \le 19$；$a = 3b - 40 \ge 1 \Rightarrow b \ge 14$（$b \ge \frac{41}{3} \approx 13.67$）。故 $b \in \{14,\dots,19\}$ 共 6 个。

逐个代入 $l = 40-2b$、$a = 3b-40$：$(a,b,l) = (2,14,12),(5,15,10),(8,16,8),(11,17,6),(14,18,4),(17,19,2)$，每组都满足 $a+b+2l=40$。

顺手验证通项：区间长度约为 $\frac{P}{2} - \frac{P}{3} = \frac{P}{6}$，$P = 40$ 时 $\frac{40}{6} \approx 6.7$，取整后 6，与枚举一致。

要点：个数约等于周长的六分之一。区间下界 $\approx\frac{P}{3}$ 来自上底为正，上界 $\approx\frac{P}{2}$ 来自腰为正，两端各由一条边决定——这是"四个正整数边"题的标准计数框架。

第 3 题 · 附加下底约束 ★★★ 形式｜附加约束子计数

回到周长 30 的原题，但现在只统计上底 $AD \ge 8$ 的梯形。这样的梯形有多少个？

👉 点击查看解析
答：2 个：$(AD,BC,AB) = (9,13,4)$ 与 $(12,14,2)$

先看周长 30 的全部四个解：$(3,11,8)$、$(6,12,6)$、$(9,13,4)$、$(12,14,2)$（上底依次为 $3,6,9,12$）。

加约束 $a \ge 8$，只剩上底为 $9$ 与 $12$ 的两个，答 2 个。

也可以不枚举直接算：$a = 3b - 30 \ge 8 \Rightarrow b \ge \frac{38}{3} \approx 12.67 \Rightarrow b \ge 13$，而 $b \le 14$，故 $b \in \{13,14\}$ 两个值。

进阶一问：若约束改成"腰 $AB \ge 5$"呢？由 $l = 30 - 2b \ge 5 \Rightarrow b \le 12.5 \Rightarrow b \le 12$，配合 $b \ge 11$ 得 $b \in \{11,12\}$，也是 2 个（对应 $(3,11,8)$ 与 $(6,12,6)$）。

要点：附加约束不要重新枚举，把它折成区间端点的新不等式即可——$AD \ge 8$ 只是把下界 $11$ 抬到 $13$，腰和上底的约束一个都没松。

第 4 题 · 周长设为 6m 的通项 ★★★★ 形式｜一般化通项 + 证明

证明：若周长为 $P = 6m$（$m$ 为正整数），则满足条件的梯形恰有 $m - 1$ 个。并据此求出周长为 $48$ 时梯形的个数。

👉 点击查看解析
答：$m-1$ 个；周长 48（$m=8$）时为 7 个

由 $2b + l = 6m$、$l \ge 1$、$a = 3b - 6m \ge 1$：

$$l \ge 1 \Rightarrow 6m - 2b \ge 1 \Rightarrow b \le \frac{6m-1}{2} = 3m - \tfrac12 \Rightarrow b \le 3m-1,$$ $$a \ge 1 \Rightarrow 3b \ge 6m + 1 \Rightarrow b \ge \frac{6m+1}{3} = 2m + \tfrac13 \Rightarrow b \ge 2m+1 .$$

于是整数 $b$ 的取值恰为 $2m+1,\, 2m+2,\, \dots,\, 3m-1$，共

$$(3m-1) - (2m+1) + 1 = m - 1 .$$

验证（$m=1,2,3,4,5$）：$P = 6,12,18,24,30$ 分别给出 $0,1,2,3,4$ 个，与 $m-1$ 全部吻合；原题 $P=30 \Rightarrow m=5 \Rightarrow 4$ 个，正是 (E)。

取 $m = 8$：$P = 48$，个数 $= 8 - 1 = \boxed{7}$。

要点：通项里的常数不是凑出来的——下界 $2m+1$ 与上界 $3m-1$ 都带 $+1/-1$ 的修正，那正是"$a \ge 1$ 而非 $\ge 0$"、"$l \ge 1$ 而非 $\ge 0$"带来的。写通项时务必先取整，别写 $\frac{m}{6}$ 这种近似。

第 5 题 · 反过来定周长 ★★★★★ 形式｜反向存在性

给定任意正整数 $N$，求使梯形个数恰好等于 $N$ 的最小周长 $P$。当 $N = 10$ 时，这个 $P$ 是多少？

👉 点击查看解析
答：最小周长 $P = 6N - 1$；$N = 10$ 时 $P = 59$

先看两个"标杆"周长。仍由 $2b + l = P$、$l\ge1$、$a = 3b - P \ge 1$：

  • $P = 6m$ 时（如 EX4）个数为 $m - 1$；
  • $P = 6m - 1$ 时：$l \ge 1 \Rightarrow b \le \frac{6m-2}{2} = 3m-1$；$a \ge 1 \Rightarrow b \ge \frac{6m}{3} = 2m$。于是 $b \in [2m,\, 3m-1]$，共 $(3m-1) - 2m + 1 = m$ 个。

要个数 $= N$，取 $m = N$、$P = 6N - 1$ 即可得到 $N$ 个。

为什么是最小？个数约为 $P/6$，程序穷举 $N = 1,\dots,12$ 的最小 $P$ 依次是 $5,11,17,23,29,35,41,47,53,59,65,71$，恰为 $6N-1$；严格地说，$P \le 6N-2$ 时区间长度 $\le \frac{P}{6} + \frac{1}{2} < N$，装不下 $N$ 个整数解。

取 $N = 10$：$P = 6\cdot10 - 1 = \boxed{59}$。

要点：反向题的正向解法是"解数与区间长度同时变"的单调性：$P$ 每增 1 可数出的梯形数不减少（$\frac{P}{6}$ 缓升），所以"最小 $P$"就是"$N$ 第一次出现"的 $P$。相邻的两个 $6m$ 与 $6m-1$ 分别给出 $m-1$ 与 $m$，正好把整数段填满、不留空隙。

六、方法总结卡片（贴在错题本上）

60° 等腰梯形 · 三行卡

  1. 认等腰：$AB = DC$ ⇒ 上下底对称，$\angle B = \angle C$，两腰在水平方向各让出 $l\cos 60^\circ = \dfrac l2$ ⇒ 上底 $a = b - l$（是减不是加）。
  2. 压成一元：周长 $a + b + 2l = (b-l) + b + 2l = 2b + l = P$。只剩 $b$ 一个自由量，$l = P - 2b$，$a = 3b - P$。
  3. 写死两条不等式：$l \ge 1 \Rightarrow b \le \left\lfloor\frac{P-1}{2}\right\rfloor$；$a \ge 1 \Rightarrow b \ge \left\lceil\frac{P+1}{3}\right\rceil$。个数 $=$ 区间内整数个数；$P = 6m$ 给 $m-1$ 个，$P = 6m-1$ 给 $m$ 个。

口诀：底角六十投影半，上底等于下底减腰；周长压成一个量，整数区间数一数。
